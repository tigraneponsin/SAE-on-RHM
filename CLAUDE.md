## 1. Project Overview

This project studies how deep transformers learn hierarchically compositional data,
using Sparse Autoencoders (SAEs) to interpret the internal representations.

### The Random Hierarchy Model (RHM)

The RHM is a synthetic classification task with a tree-structured generative process.
Data is generated top-down from class labels to input tokens:

- **Level 0**: Class label (one of `n` values). This is the root.
- **Level 1**: `s` features, each from a vocabulary of `v` values. Generated by
  applying one of `m` synonymic production rules to the class label.
- **Level l**: `s^l` features. Each node at level `l-1` generates `s` children at
  level `l` via one of `m` random rules.
- **Level L**: `s^L` leaf features = the input tokens the transformer sees.

Key parameters: `v` (vocabulary size), `n` (number of classes), `m` (number of
synonymic rules per node), `s` (tuple size / branching factor), `L` (number of
hierarchy levels).

The `trees` dictionary stores ground truth at every level:
- `trees[0]`: shape `(num_samples,)` -- class labels
- `trees[l]`: shape `(num_samples, s^l)` -- intermediate latent values
- `trees[L]`: shape `(num_samples, s^L)` -- leaf tokens (model input)

The key paper result (Cagnetta et al., Phys. Rev. X 14, 2024): deep networks learn
this task with sample complexity `P* ~ n_c * m^L`, polynomial in input dimension,
by building internal representations invariant to exchanging synonymic features.

### What We Expect the Transformer to Do

The transformer (depth >= L) is hypothesized to resolve the hierarchy level by level,
bottom-up:

- **Transformer layer 0** processes the raw leaf tokens and should learn to identify
  which level-(L-1) parent generated each group of `s` adjacent tokens. This is the
  first composition step: grouping `s` leaves into their level-(L-1) ancestor.
- **Transformer layer 1** should resolve level-(L-2): grouping `s` level-(L-1)
  representations into their level-(L-2) ancestor.
- **Transformer layer k** should resolve level `L-1-k` in general.
- **Transformer layer L-1** (the last) should resolve level 0: the class label.

This is the "synonymic invariance" hypothesis from the paper: at layer `k+1`, the
representation should be invariant to exchanging synonymic groups at level `L-k`.

### SAE Goal

The SAE is trained on the residual stream activations at a specific (layer, token
position) to decompose them into sparse, interpretable features. The hope is that
SAE latent features correspond to the ground truth RHM latents at the appropriate
hierarchy level. For example, an SAE at layer 0 on token 0 should recover features
that correspond to the level-(L-1) ancestor of token 0.

### Transformer Architecture Details

**ClassificationTransformer** (`transformer_class`):
- Sequence: `[CLS] + s^L real tokens` (total length `s^L + 1`)
- CLS token at position 0 (learnable parameter), real tokens at positions 1..s^L
- Classification from CLS token only
- Pre-norm residual blocks: `x = x + attn(LN(x))`, `x = x + ffn(LN(x))`

**MeanClassificationTransformer** (`transformer_meanclass`):
- Sequence: `s^L real tokens` (no CLS)
- Classification from mean of all token representations
- Same block structure

**Token position offset**: For `transformer_class`, the real token at 0-based index
`token_idx` sits at sequence position `1 + token_idx` (because CLS is at 0).
For `transformer_meanclass`, it sits at sequence position `token_idx`.

### SAE Training Setup

SAE hooks into `model.blocks[layer_id]` to capture the post-block residual stream
output. Token selection modes:
- `one_token`: single real token at index `sae_token_idx`
- `all_tokens`: all real tokens (skips CLS for `transformer_class`)
- `cls_token`: CLS token only (`transformer_class` only)

Activation scaling: `act_scale = sqrt(embedding_dim) / E[||x||_2]`, applied before
the SAE. The scale factor is stored in the SAE checkpoint under
`sae_training_setup.act_scale`.

### Checkpoint Formats

**Transformer** (.pt):
```
{
  'config': argparse.Namespace (all training hyperparams),
  'output': {
    'model': state_dict,
    'rules': dict (RHM rules used),
    'best': {'step', 'loss', 'model'},
    'dynamics': [{'t', 'testloss', 'testacc'}, ...],
  }
}
```

**SAE** (.pt):
```
{
  'config': transformer config,
  'source': {'train_output': path_to_transformer},
  'sae_layers': [layer_ids],
  'sae_state': {layer_id: state_dict},
  'sae_metrics': {layer_id: {total_loss, recon_loss, ...}},
  'sae_training_setup': {
    'sae_activation_source': str,
    'sae_token_idx': int,
    'act_scale': {str(layer_id): float},
  },
}
```

## 3. Linear Probe Implementation (NEW)

### Purpose

Train a linear classifier on residual stream activations at (layer k, token p) to
predict the ground truth RHM latent at hierarchy level `L-1-k`. This serves two goals:

1. **Verify** that intermediate latents are linearly decodable from the residual stream
   (confirms the transformer has learned the hierarchical composition).
2. **Measure SAE quality**: train the probe on clean activations, then evaluate on
   SAE-reconstructed activations. The accuracy drop quantifies how much intermediate
   latent information the SAE destroys.

### Target Latent Mapping

For a probe at transformer layer `k`, token position `p` (0-based real token index):
- Target hierarchy level = `L - 1 - k`
- Ancestor position at that level = `p // s^(1+k)`
- Target label = `trees[L-1-k][sample, p // s^(1+k)]`
- Label vocabulary = `v` values (for levels 1..L-1) or `n` values (for level 0)
