# Circuit Tracing Implementation Plan

## Context

We are implementing the procedure described in `.docs/circuit_tracing_handoff.md`: a per-input attribution DAG over SAE features for a transformer trained on the Random Hierarchy Model. The transformer + SAE pipelines, the conditional-stat eval (`scripts/sae_eval/streaming.py`), and the simple tree reconstruction (`scripts/sae_tree_reconstruction/run.py`) already work. This is the next step: take a single input, run the linearized forward pass with SAE insertion, compute feature-to-feature and feature-to-logit attribution edges, prune, and save the resulting graph plus fidelity diagnostics.

> **Note (2026-05).** The pruning step (Step G), the final-layer sink, and
> the inclusion of embedding nodes were revised after the initial cut. See
> `.docs/circuit_pruning.md` for the authoritative specification of those
> pieces; this document was updated in-place to match. Steps A--F (anchor
> capture, linearization, bit-identity, edge-weight math) are unchanged
> from the original plan and remain authoritative here.

The output is a tool (`circuit_tracing/circuit_trace.py`) that, given a transformer checkpoint, K SAE checkpoints (one per layer, in bottom-to-top order), K matching `.sae_eval.pt` artifacts (for latent labels), and a single input index, produces:

- `nodes.pt`, `edges.pt`, `fidelity.pt`, plus a `networkx.DiGraph` for that input.
- Stdout: bit-identity assertion, per-layer error mass, feature-mediated logit fraction.

No visualization in this first deliverable.

## Decisions (locked)

- **SAE splice point**: post-block, hooking `model.blocks[k]` output (matches `train_sae.py`). For the final-layer-to-logits step, freeze the per-position scale of `ln_f` from the original forward pass, then apply mean-pool + classifier. Keeps the whole pipeline affine.
- **Linearized block representation**: hybrid. Implement `M_{k+1}` as a closure that takes a residual-stream perturbation `[N, d]` and returns `[N, d]` with all anchors (attention pattern, ln1/ln2 scales, MLP ReLU mask, and ln_f scale at the final layer) frozen. If `N*d <= 8192` (configurable threshold), materialize `M_{k+1}` once as `[N*d, N*d]` by probing with unit vectors; reuse for all edge computations. Otherwise compute each row of attribution on demand by running the closure on `(W_dec_k[:, i] / act_scale_k)` placed at position `p`.
- **Variants supported**: both `transformer_meanclass` and `transformer_meanclass_nores`, switched via a single boolean derived from the model class. The block linearization adds the residual identity if and only if the variant has residuals.
- **Attribution mode**: Auto-hybrid threshold default 8192. CLI flag `--mat_threshold`.
- **Latent labels**: required. Caller passes K `.sae_eval.pt` artifacts. The right conditional is `P(latent_value = v | feature_f fires)` — *not* `P(fire | value)`. This is exactly what `_build_cond_prob` in `scripts/sae_tree_reconstruction/run.py:213` returns: `cond_prob[v, p, f] = joint_fire_count[v_in_group, p, f] / firing_count[p, f]`. For each (layer k, position p, feature f), the label is `argmax_v cond_prob[v, p, f]` evaluated at the relevant group `(level=L-1-k, position=p // s^(1+k))`. So for a fixed feature that fired at a fixed position (-> fixed parent), we have a vector of empirical posterior probabilities over latent values; argmax names the most likely parent latent value given that the feature fires. Label format stored on the node: `{'level': L-1-k, 'parent_position': p // s^(1+k), 'value': v_argmax, 'p_value_given_fire': float}`.
- **Single input per run** (`--input_idx`). One eval seed; the row at that index is selected from a freshly sampled set drawn under the *exact same RHM rules* used to train the transformer (see Rules-consistency invariant below).

- **Rules-consistency invariant (critical)**: the transformer, every SAE, every `.sae_eval.pt` artifact, and the new input we generate must all be produced under the *same* RHM rules object. Concretely:
  1. Treat `blob['output']['rules']` from the transformer checkpoint as the canonical source of truth and use `load_transformer(...)` (which already returns these exact rules via `resolve_rules`).
  2. For each SAE checkpoint, read `ckpt['sae_dataset_split']['rules_source']` and `['rules_seed']`. Require either `rules_source == 'artifact'` (SAE was trained against the saved rules object) OR `rules_source == 'seed_rules_resampled'` *with* `rules_seed == cfg.seed_rules` from the transformer.
  3. For each `.sae_eval.pt` artifact, read `rules_source` and `sae_rules_source`; require they match the transformer's `rules_source` (mirrors the existing check at `scripts/sae_eval/run.py:381`).
  4. The new input we trace is sampled by passing the canonical `rules` object into `sample_trees(...)` with a user-supplied `--eval_seed`. Do NOT regenerate rules from `seed_rules` for the input even if the SAE was. This guarantees the leaf sequence we attribute against is generated by the same hierarchical decomposition the transformer learned.
  5. Hard-fail with a clear error message on any mismatch. Log all four `(rules_source, rules_seed)` pairs at the start of every run for human verification.
- **First deliverable**: end-to-end script with fidelity + saved DAG, no matplotlib viz yet.

## Implementation steps

### Step A — CLI and loading (`circuit_trace.py`)

CLI:
```
python -m circuit_tracing.circuit_trace \
  --train_output path/to/transformer.pt \
  --sae_ckpts path0.pt path1.pt path2.pt \
  --sae_eval_artifacts eval0.pt eval1.pt eval2.pt \
  --input_idx 42 \
  --eval_seed 0 \
  --eval_size 1024 \
  --output_dir runs/circuit_trace/example \
  --mat_threshold 8192 \
  --sink_mode softmax_logits \
  --node_threshold 0.8 \
  --edge_threshold 0.98 \
  --device cuda \
  --model_variant best
```

`--prune_fraction` (the original single-threshold knob) has been removed.
Passing it raises an explicit migration error pointing to `--sink_mode`,
`--node_threshold`, and `--edge_threshold`.

A slurm wrapper exists at `slurm/sae/run_circuit_trace.sh` that takes the
same flags. Because the slurm job's `--chdir` is the user's home (not the
repo), the wrapper exports `PYTHONPATH=${REPO_DIR}` before `srun python -m
circuit_tracing.circuit_trace ...`.

- Load transformer via `load_transformer(..., shuffle=False)` so `--input_idx` indexes deterministically into `trees`. Capture the returned `rules` and `rules_source` as the canonical reference.
- Load SAEs via `load_sae(...)` per layer; assert `len(sae_ckpts) == cfg.num_layers`. Assert each SAE's `layer_id` matches its position in the list. For each SAE, run the rules-consistency check (Rules-consistency invariant #2): `sae['sae_rules_source']` must equal `rules_source`, and if it is `'seed_rules_resampled'` the SAE's `dataset_split.rules_seed` must equal `cfg.seed_rules`.
- Load each `.sae_eval.pt` artifact. Assert `layer_id`, `rhm` params, and `latent_dim` match the SAE. Run the rules-consistency check (#3) on the artifact's `rules_source` / `sae_rules_source`.
- Re-sample trees for the new input from the canonical rules: `trees = sample_trees(num_data=eval_size, rules=rules, seed=eval_seed)`. This is the key step that guarantees we attribute against an input drawn from the same hierarchical generative process. The `loader` returned by `load_transformer` already does this; we only re-do it explicitly if we want a different `eval_seed` or `eval_size` than the loader was built with.
- Detect variant: `isinstance(model, MeanClassificationTransformerNoResidual)` -> `has_residual = False`, else `True`. **Caveat**: `init.init_model` wraps the transformer in `torch.compile` when `device='cuda'` (see `init.py:280`), producing a `torch._dynamo.OptimizedModule` whose underlying module is at `._orig_mod`. The linearization code calls a small helper `_unwrap_compiled(model)` (= `getattr(model, '_orig_mod', model)`) at every entry point so the `isinstance` check, `model.blocks[k]`, `model.ln_f`, and `model.classifier` work uniformly for compiled and uncompiled models. The orchestrator does the same unwrap once after `load_transformer` so the rest of `circuit_trace.py` operates on the raw `nn.Module`.
- Pick the single input row: `x = trees[L][input_idx]` (shape `[N]`), `y_true = trees[0][input_idx]`. Verify `transformer_meanclass`/`_nores` token offset rules from CLAUDE.md (no CLS, real token i at position i).
- Print, for human verification: transformer `rules_source`, transformer `seed_rules`, every SAE's `(rules_source, rules_seed)`, every artifact's `(rules_source, sae_rules_source)`. Hard-fail on any mismatch.

### Step B — Original forward pass + anchor capture (`linearize.py`)

Run `model(x.unsqueeze(0))` with hooks that cache, per block index k:

- Pre-block input to ln1 (call it `r_k_in`, shape `[N, d]`). For k=0, this is `tok_emb + pos_emb`. For k>0, this is the previous block's output.
- `ln1_scale_k`, `ln1_mean_k`: from `nn.LayerNorm`'s computed mean and rsqrt of variance for each position. Capture by re-running the same op outside the hook, since `nn.LayerNorm` doesn't expose these directly.
- `attn_pattern_k[h, i, j]` post-softmax: from `MultiHeadAttention.forward` — easiest is to monkeypatch or subclass to expose the pre-projection softmax weights. Implementation: register a forward hook on `block.attn` that calls a wrapped version computing q/k/softmax explicitly with the same parameters. Less invasive: copy the four lines from `models/transformer.py:62-69` into our anchor-capture code, since we already have the block's parameters.
- `ln2_scale_k`, `ln2_mean_k`: same treatment as ln1, on the post-attn (post-residual if applicable) tensor.
- `mlp_relu_mask_k`: forward hook on `block.ffwd` that captures `(pre_act > 0).float()` from the hidden layer of `MLP`. Read `models/fcn.py` once to confirm the hidden activation is exactly one `ReLU` (or refactor the MLP forward to expose the pre-activation).
- `x_k`: post-block residual stream, `[N, d]`. This is the SAE's input.
- Final: `ln_f_scale`, `ln_f_mean` on `x_{K-1}`, then `pooled = x_hat_post_lnf.mean(0)`, then `logits = classifier(pooled)`.

All anchors are computed in float32, detached, on the same device as the model.

Sanity: re-applying the captured anchors as an affine sequence to the very same `r_0_in` must reproduce `logits` to ~float32 precision. Assert this before proceeding.

### Step C — SAE pass and error nodes (`circuit_trace.py`)

For each layer k:

```
x_scaled_k = act_scale_k * x_k
z_k = ReLU(W_enc_k @ x_scaled_k.T + b_enc_k[:,None]).T   # [N, latent_dim]
x_hat_scaled_k = (W_dec_k @ z_k.T).T + b_dec_k
x_hat_k = x_hat_scaled_k / act_scale_k                    # back to residual-stream space
e_k = x_k - x_hat_k                                       # error node, [N, d]
```

`act_scale` consistency assertion: `torch.allclose(x_hat_k + e_k, x_k, atol=1e-5)`. By construction this is exact.

### Step D — Bit-identity check via spliced replay

Run the linearized forward pass, but instead of feeding `x_k` to block k+1, feed `x_hat_k + e_k`. By construction this equals `x_k`, so logits must match the original to float32 precision. Assert this. This is the "fidelity test #1" from the handoff.

### Step E — Build the `M_{k+1}` closure (`linearize.py`)

`M_{k+1}(v)` for an input perturbation `v` of shape `[N, d]`:

Given the captured anchors at layer k+1:
1. `u = (v - ln1_mean_{k+1}) * ln1_scale_{k+1} * ln1_gamma_{k+1}` (LayerNorm is affine on the perturbation around the anchor; we drop the bias term since we are differentiating around a fixed point — this is exactly equivalent because the contribution of the constant offset cancels in linear attribution. Implementation note: compute `LayerNorm(x_anchor + eps*v) - LayerNorm(x_anchor)` to first order — equals applying gamma * (1/sigma) * (v - mean(v)) per position. Use this exact form.)
2. Apply attention with frozen pattern: `attn_out[i] = sum_h sum_j attn_pattern_{k+1}[h, i, j] * (W_O_h @ W_V_h @ u[j])`. This is just linear in `u`.
3. Add residual: `r1 = u + attn_out` if `has_residual`, else `r1 = attn_out`. (Here "u" is post-ln1; we add back the original perturbation pre-ln1 if residual.)

Wait — need to be careful: in the actual block, the residual adds the *pre-ln1 input*, not the post-ln1 result. Restating the block:
```
y = x + dropout(attn(ln1(x)))     # pre-norm, residual adds the pre-ln1 x
y = y + dropout(ffwd(ln2(y)))
```

So for the linearization on a perturbation `v` (representing a perturbation in the residual stream input to block k+1):
- `attn_branch(v) = attn_linearized(ln1_jvp(v))` where `ln1_jvp(v) = ln1_gamma * (1/ln1_sigma) * (v - mean(v))` and `attn_linearized` is the frozen-pattern attention.
- `attn_out = attn_branch(v)`
- `intermediate = v + attn_out` (residual) or `intermediate = attn_out` (no residual).
- `mlp_branch(intermediate) = W_out_diag @ ffwd_relu_mask * (W_in @ ln2_jvp(intermediate))`
- `output = intermediate + mlp_branch(intermediate)` (residual) or `output = mlp_branch(intermediate)` (no residual).

Implement `M_{k+1}(v)` as a callable returning this `output`, with all the listed anchors closed over.

If `N*d <= mat_threshold`: materialize as a `[N*d, N*d]` matrix by calling the closure on each canonical basis vector. Cache per layer.

### Step F — Edge weight computation (`attribution.py`)

For each layer k from 0 to K-2:

- Collect the set of active features at layer k+1: `active_{k+1} = {(j, q) : z_{k+1}[q, j] > 0}`.
- For each active `(j, q)`:
  - The pre-activation of feature j at position q is `(W_enc_{k+1}[j, :] @ act_scale_{k+1} @ x_{k+1}[q, :]) + b_enc_{k+1}[j]` — but we want to decompose it as a sum of contributions from layer-k features and the layer-k error node. Since `x_{k+1} = block_{k+1}(x_k) = block_{k+1}(x_hat_k + e_k)` and `block_{k+1}` is affine when linearized, we can write `x_{k+1}[q] = block_{k+1}(x_hat_k)[q] + M_{k+1}_{q,p_set}(e_k)[q] + const_terms`. Drop the `const_terms` (independent of input perturbations); they're absorbed into the bias. Decompose `x_hat_k = sum_{i, p : z_k[p,i]>0} z_k[p,i] * (W_dec_k[:, i] / act_scale_k)` placed at position p. Each summand is a localized perturbation `v_{i,p}[r, :] = delta(r=p) * z_k[p,i] * (W_dec_k[:, i] / act_scale_k)`. Then attribution from feature i at (k, p) to feature j at (k+1, q) is:
    ```
    contribution[j, q <- i, p] = act_scale_{k+1} * W_enc_{k+1}[j, :] @ M_{k+1}( v_{i,p} )[q, :]
    ```
    Using linearity: `= z_k[p, i] * act_scale_{k+1} * W_enc_{k+1}[j, :] @ M_{k+1}( delta_{p} ⊗ (W_dec_k[:, i] / act_scale_k) )[q, :]`.
  - Error contribution: place `e_k[p]` at position p (pure delta in p), feed to `M_{k+1}`:
    ```
    contribution[j, q <- err, k, p] = act_scale_{k+1} * W_enc_{k+1}[j, :] @ M_{k+1}( delta_{p} ⊗ e_k[p] )[q, :]
    ```
  - Note: I am including the `act_scale_{k+1}` factor explicitly because the SAE pre-activation is computed on `act_scale_{k+1} * x_{k+1}`. This is the doc's "edge weight formula" written more carefully — the doc bakes it into `W_enc_{k+1}` implicitly. Either is fine as long as the bit-identity check passes.

Implementation: when `M_{k+1}` is materialized, all of this becomes one big matmul. When closured, run `M_{k+1}` once per (i, p) pair if there are fewer active source features, otherwise once per (j, q) target via the transpose (VJP).

For the final layer K-1, the "next layer" is the logit head:
- `pooled_hat = ((x_hat_{K-1} - ln_f_mean) * ln_f_scale * ln_f_gamma).mean(0)` (frozen ln_f).
- `logit_c = W_cls[c, :] @ pooled_hat + b_cls[c]`.
- Attribution `feature i at (K-1, p) -> logit c`: `(1/N) * W_cls[c, :] @ ln_f_jvp_at_p(W_dec_{K-1}[:, i] / act_scale_{K-1}) * z_{K-1}[p, i]`.
- Attribution `error at (K-1, p) -> logit c`: `(1/N) * W_cls[c, :] @ ln_f_jvp_at_p(e_{K-1}[p])`.

These per-class attributions are saved as separate edges to per-class logit
sink nodes (`('logit', c)` for `c in range(num_classes)`); the original
single `'logit_diff'` sink has been dropped. See Step G for how the per-class
sink is weighted (softmax-of-logits or 1.0 on the true class).

### Step F.embed — Embedding -> layer-0 attribution

Add embedding nodes as new graph inputs. One node per leaf position p with
key `('embed', p)` and "activation" `e_emb[p] = tok_emb[x[p]] + pos_emb[p]`
(captured already inside `anchors.embed`).

For each embedding node and each active layer-0 feature `(0, q, j)` (i.e.
`z_0[q, j] > 0`):

```
contribution[(0, q, j) <- ('embed', p)]
  = act_scale_0 * W_enc_0[j, :] @ M_0(delta_p (x) e_emb[p])[q, :]
```

`M_0` is the same closure construction as `M_{k+1}` for `k >= 0`, anchored
at `anchors.blocks[0].r_in == anchors.embed`. No new linearization
machinery is needed; the existing `make_M(model, 0, anchors)` / `materialize_M`
both work directly. Reuses the same dense-source helper as the err->feat
edges in Step F.

Embedding nodes are PURE INPUTS: no incoming edges in the DAG, exactly like
error nodes. They are never pruned.

### Step G — DAG construction and pruning (`dag.py`, `prune.py`)

Nodes (four kinds):
- `('feat', k, p, i)` for every active feature where `z_k[p, i] > 0`.
- `('err', k, p)` for every (layer, position).
- `('embed', p)` for every leaf position (Step F.embed).
- `('logit', c)` for every class `c in range(num_classes)`.

The node attribute `kind` carries the human-readable name (`'feature'`,
`'error'`, `'embedding'`, `'logit'`). Embedding nodes record `token_id`,
`level=0`, `parent_position=p // s` (so they group by leaf-group of size `s`,
matching subtree-alignment scoring). Logit nodes record `class`, `logit`,
`prob = softmax(logits)[c]`, and `is_true_class`.

Edges:
- Adjacent-layer feature->feature, error->feature with weights from Step F.
- Embedding->layer-0-feature with weights from Step F.embed.
- Final-layer feature->logit_c and error->logit_c (one per class) with
  weights from Step F.

**Pruning: indirect-influence (replaces the old top-fraction-by-|weight| rule).**

Pruning is two-stage (nodes first, then edges) and uses the polynomial form
of the indirect-influence matrix on the unsigned, row-normalized adjacency.
Embedding, error, and logit nodes are inputs/sinks and are never pruned.
Only feature nodes are prunable.

1. Build the signed adjacency `W` indexed `[target, source]` and the
   unsigned, row-normalized `A = |W| / row_sums` (rows of pure-input nodes
   stay zero). Order nodes so that virtual layer indices are strictly
   increasing along edges: embedding=-1, feature/error at layer k = k,
   logit = K. Verifies the DAG ordering on adjacency build (hard-fails on
   any backward edge).

2. Compute the indirect influence
   ```
   B = A + A^2 + ... + A^(K+2)
   ```
   via the polynomial form (longest path is K+1 hops; one extra iteration is
   a cycle-detection guard). With strict-DAG ordering `A` is nilpotent and
   the sum is exact in <= K+2 iterations. Hard-fails if `A^(K+2)` is not
   essentially zero. Note: with `W[target, source]` indexing, "node score
   for source j" is `(B.T @ logit_weights)[j]`, not `(B @ logit_weights)[j]`.

3. Build `logit_weights` of shape `[N_nodes]` via `--sink_mode`:
   - `softmax_logits` (default): `softmax(logits)[c]` at every logit node.
     All `v` classes are kept (no top-K cap; `v` is small in RHM configs).
   - `true_class`: `1.0` at `('logit', y_true)`, zero elsewhere.

4. **Node prune**: `node_score = B.T @ logit_weights`. Sort prunable
   (kind == 'feature') nodes by `node_score` descending; keep the smallest
   prefix where cumulative score / total >= `--node_threshold` (default
   `0.8`); include the threshold-crossing node. If the total prunable score
   is zero, keep all features and warn (can happen when softmax-of-logits is
   degenerate or the model is silent).

5. **Edge prune**: restrict edges to the kept-feature subgraph (union with
   embedding/error/logit). Recompute `A_sub` on the subgraph and `B_sub`,
   then `node_score_sub = B_sub.T @ logit_weights`. Override the logit-node
   entries: `node_score_sub[i] = logit_weights[i]` for logit indices i
   (logits have no outgoing edges so they would otherwise score zero, and
   every edge into a logit would survive only by accident -- this matches
   Anthropic's pseudocode). Edge score:
   ```
   edge_score[t, s] = A_sub[t, s] * node_score_sub[t]
   ```
   Sort all subgraph edges by edge_score descending; keep the smallest
   prefix to `--edge_threshold` (default `0.98`).

6. **Diagnostics** (saved to `fidelity.pt`):
   - `n_nodes_pre_by_kind`, `n_nodes_post_by_kind` (per `feature`/`error`/
     `embedding`/`logit`).
   - `n_edges_pre_prune`, `n_edges_post_prune`.
   - `completeness_score`: fraction of `|signed_weight|` on incoming edges
     to kept feature/logit nodes that comes from feature or embedding sources
     (i.e. not error). Computed on the pruned subgraph.
   - `replacement_score`: zero out the *columns* of `A_sub` corresponding to
     error nodes (block any flow leaving an error node), recompute
     `B_no_err`, and report the ratio of embedding-to-logit path mass with
     vs. without errors. Under `softmax_logits`, weight per-class by
     `softmax(logits)[c]` and average.

> Spec deviation, intentional: the original spec wording said "zero error
> *rows* of A". In the `[target, source]` indexing those rows are already
> zero (errors have no incoming edges), so the no-op was clearly not the
> intent; we zero columns instead, which removes errors as flow sources.

Save:
- `nodes.pt`: dict `key -> attrs`. Per kind:
  - `'feature'`: `{kind, layer, position, feature, z, level, parent_position, label_value, p_value_given_fire, eval_firing_count}`.
  - `'error'`: `{kind, layer, position, level, parent_position}`.
  - `'embedding'`: `{kind, position, token_id, level, parent_position, e_emb_norm}`.
  - `'logit'`: `{kind, class, logit, prob, is_true_class}`.
- `edges.pt`: `{'all': [...], 'pruned': [...]}`. Each entry: `(src_key, dst_key, signed_weight)`. Both lists use the original signed weights (not the unsigned/normalized ones used internally for pruning).
- `fidelity.pt`: existing fields (`bit_identity_max_err`, `per_layer_error_fraction`, `feature_mediated_logit_fraction`, `subtree_alignment_fraction`, `per_layer_subtree_alignment`, `y_true`, `y_pred`, `y_runner_up`, `logits`, `rhm`) PLUS `sink_mode`, `node_threshold`, `edge_threshold`, `n_nodes_pre_by_kind`, `n_nodes_post_by_kind`, `n_edges_pre_prune`, `n_edges_post_prune`, `completeness_score`, `replacement_score`. The old `logit_diff` scalar is dropped.
- `graph.gpickle` (networkx DiGraph) for downstream use.

### Step H — Diagnostics (`circuit_trace.py`, end of run)

Print to stdout:
- Bit-identity max error.
- Per-layer error fraction (handoff Step §Fidelity diagnostics #2).
- Feature-mediated logit fraction (handoff #3). Computed per-class then
  averaged with the `--sink_mode` weights (`softmax(logits)[c]` or
  delta-on-y_true).
- Subtree alignment fraction: fraction of total edge mass across
  feature->feature edges where `q == p // s` (handoff RHM-specific check).
  Embedding->layer-0 edges are included as a new "k=-1" slot using
  `group = s` (i.e. an edge `('embed', p_src) -> ('feat', 0, q_dst, j)` is
  aligned iff `p_src // s == q_dst // s`).
- `--sink_mode`, `--node_threshold`, `--edge_threshold`.
- Per-kind node counts pre/post pruning, pre/post edge counts.
- `completeness_score`, `replacement_score`.

## Verification

End-to-end test (manual; not a unit test for the first cut):

1. Pick a small RHM config that has a trained transformer + 3 SAEs already on disk. Use `transformer_meanclass_nores` if available since the math is cleaner.
2. Run `python -m circuit_tracing.circuit_trace ...` on `--input_idx 0` with the defaults (`--sink_mode softmax_logits --node_threshold 0.8 --edge_threshold 0.98`).
3. Confirm:
   - Bit-identity max error < 1e-4 (float32 reasonable bound).
   - Per-layer error fraction printed; flag any layer > 0.2.
   - Feature-mediated logit fraction printed and > 0.8 if SAEs are good.
   - Embedding nodes appear: exactly `s^L` of them.
   - Logit nodes: exactly `num_classes` (all classes) under `softmax_logits`.
   - `n_features_pre / n_features_post` is roughly 3x-30x at the default
     thresholds; flag if outside that range.
   - `completeness_score >= 0.7` if SAEs are good; `replacement_score`
     usually a bit lower (0.5-0.7).
   - `subtree_alignment_fraction >= 0.5`. Lower means SAEs are leaking
     levels.
   - Output files exist with non-empty contents.
4. Re-run with `--sink_mode true_class`. Confirm exactly one logit node has
   `is_true_class=True`. Confirm the graph differs from `softmax_logits`
   (more diverse paths in the latter when the model is uncertain).
5. Re-run with `--node_threshold 0.95 --edge_threshold 0.99`; confirm more
   nodes/edges kept and `completeness_score` rises.
6. Re-run with `--node_threshold 0.5`; confirm aggressive pruning and a
   drop in `completeness_score`.
7. Re-run with `--input_idx 1` and confirm the graph differs (sanity — graphs are input-dependent).
8. Re-run on `transformer_meanclass` (with residual) and confirm bit-identity still holds.
9. Pick a misclassified input under `--sink_mode true_class`; confirm small
   total path mass on the logit and a structurally degenerate graph
   (low `subtree_alignment_fraction`).

If any assertion fails, fix before extending. Visualization is a follow-up.

## Out of scope (deferred)

- Visualization (networkx layered layout, edge coloring).
- Multi-input aggregation / dataset-level summaries.
- Automatic SAE selection by sweep (manual checkpoint paths only).
- Transcoder fallback if per-layer error mass is large.
- Attention attribution (QK circuits).
- Pruning embedding or error nodes (we never do this -- they are pure
  inputs).
- Refining `replacement_score` for high-uncertainty prompts beyond the
  softmax-weighted-average approach.
